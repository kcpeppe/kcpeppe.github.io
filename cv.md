## Summary

Independent Java performance consultant with more than two decades of practice in tuning, diagnosing, and engineering JVM-based systems. Java Champion (2006). Oracle Groundbreaker. JavaONE Rockstar. Author of the Java Performance Diagnostic Model (jPDM) and the original Java Performance Tuning workshop. Co-founder of jClarity (acquired by Microsoft in 2019) and JCrete.

Current focus: independent consulting through Kodewerk, with deep specialties in garbage collection, heap analysis at scale, application and JVM tuning, and benchmarking discipline. Currently building purpose-built tooling for heap analysis at terabyte scale — work that conventional analyzers can't perform.

## Professional Experience  

### Kodewerk Ltd. *(2005 – Present)*  
**Founder and Principal Consultant**  
- Independent consulting in Java performance tuning, garbage collection, heap analysis, benchmarking, and JVM diagnostics.
- Author and instructor of workshops in Java Performance Tuning, GC Tuning, Memory-Efficient Java, and Solving Java Memory Leaks.
- Engagements span finance, e-commerce, data infrastructure, and large in-memory systems.
- Currently building tooling for heap analysis at the terabyte scale — beyond the reach of mainstream analyzers.

### Azul Systems *(2025 – 2026)*  
**Principal Technical Account Manager**  
- Helped customers adopt Azul's technology, including tuning Prime, ReadyNow, and Orchestrator to fit customer workloads.
- Diagnosed performance regressions related to Prime in production environments.
- Authored educational material on performance tuning Prime.

### Microsoft *(2019 – 2025)*  
**Principal Engineer, Java Engineering Group**  
- Joined Microsoft as part of its acquisition of jClarity.
- Built tooling to optimize Java workloads for Microsoft customers.
- Tuned customer workloads across Azure-hosted services.
- Contributed to OpenJDK GC performance work, including the [Automatic Heap Sizing JEP](https://bugs.openjdk.org/browse/JDK-8350152).

### jClarity *(2011 – 2019)*  
**Co-founder and CTO**  
- Co-founded jClarity, focused on Java performance monitoring and optimization.
- Designed the diagnostic engine — Censum and Illuminate — built on jPDM.
- Led consulting and training for enterprise clients globally.
- Acquired by Microsoft in 2019.

### Sys-con / Java Developer's Journal *(2003 – 2004)*  
**J2EE Editor**  
- Managed editorial content related to Java Enterprise Edition.
- Wrote and published technical articles and industry analysis.
